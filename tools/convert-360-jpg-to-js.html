Конвертер 360 изображения - JS-пакет

Назначение: подготовить файл *-360.js для офлайн-режима (без сервера), чтобы движок мог грузить 360-ресурс из JS.

Входные данные

Изображение извлекается из массива dataUrl внутри пакета, сформированного этим конвертером.
Файл еще не выбран.
Normal сохраняется как IMG-360.js. Mobile сохраняется отдельно как IMG-360-mobile.js. В истории указывайте JS-пакет, а не исходное изображение.

Настройки экспорта

Normal

Mobile

Normal — основной *-360.js; mobile — *-360-mobile.js при quality=mobile.

Генерация пакетов

Ожидание.
Формат: пакет пишет данные в window.VN360_PACKS_VARIANTS по URL самого *-360.js.

Варианты экспорта

После генерации здесь появятся размеры, вес и превью normal/mobile.
