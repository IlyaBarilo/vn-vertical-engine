Новая метка

Наведите перекрестье в центре на нужную точку и нажмите «Поставить метку». Номера меток и прицелы фокуса на превью можно перетаскивать — координаты сразу пишутся в данные. Камера: ЛКМ/drag по пустому canvas — поворот, колесо — zoom.
Несколько точек входа с одинаковыми focusX/focusY (или пустой вход = как у default) дают один общий зелёный прицел — список ключей см. ниже «Точки входа».
Загрузите 360-изображение.
